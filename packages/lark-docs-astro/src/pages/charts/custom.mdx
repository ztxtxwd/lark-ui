## 使用 HTML 的自定义工具提示

对于需要自定义 HTML 格式的工具提示（Tooltip），请使用 `dangerousHtmlFormatter` 属性而不是标准的 `formatter`。这样可以让安全影响更加明确。

使用 `dangerousHtmlFormatter` 时，**强烈建议**使用 `echarts.format.encodeHTML` 对用户提供的任何内容进行净化处理，以防止 XSS 漏洞。
