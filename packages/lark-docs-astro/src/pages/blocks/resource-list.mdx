## 安装

  <p>
    ResourceListPage 是一个<strong>区块（block）</strong>——通过命令行工具（CLI）安装、
    由你拥有且可自行定制的组件。与常规组件不同，区块会被复制到你的项目中，
    因此你可以完全掌控代码。
  </p>
  <div class="space-y-4">
    <div>
      <p>**1. 初始化 Lark 配置（仅首次需要）**</p>

```bash
npx @lark-ui/core init
```

</div>
<div>
<p>**2. 安装区块**</p>

```bash
npx @lark-ui/core add ResourceListPage
```

</div>
<div>
<p>**3. 从本地路径导入**</p>

```tsx
// The path depends on your lark-ui.json blocksDir setting
// Default: src/components/lark/
import { ResourceListPage } from "./components/lark/resource-list/resource-list";
```

    </div>

  </div>
  <Callout type="info">
    <strong>为什么要用区块？</strong> 区块让你完全拥有代码，可以按自身需求定制
    布局。对于经常需要按项目定制的页面级模式，它们非常合适。
  </Callout>
</ComponentSection>

## 用法

```tsx
import { ResourceListPage } from "./components/lark/resource-list/resource-list";
import { Surface } from "@lark-ui/core";
import { DatabaseIcon } from "@phosphor-icons/react";

export default function DatabasesPage() {
  return (
    <ResourceListPage
      title="Databases"
      description="Manage your database instances and configurations"
      icon={<DatabaseIcon size={32} className="text-lark-strong" />}
    >
      <Surface className="p-6">{/* Your resource list content */}</Surface>
    </ResourceListPage>
  );
}
```
