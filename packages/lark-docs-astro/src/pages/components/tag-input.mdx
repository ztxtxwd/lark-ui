## 用法

使用 `value` 配合 `onValueChange` 来控制标签。非受控用法请使用 `defaultValue`。

```tsx
const [tags, setTags] = useState<string[]>([]);

<TagInput
  label="Labels"
  value={tags}
  onValueChange={setTags}
  placeholder="Add a label"
/>
```

### 表单
设置 `name` 可让每个标签作为独立的表单值提交，这样 `FormData.getAll(name)` 就能取回这些标签。输入框中尚未提交的文本会在失去焦点时变成标签，因此点击提交按钮时也会包含它。只要至少有一个标签，`required` 校验就会通过。
<ComponentExample demo="TagInputFormDemo"><TagInputFormDemo client:load /></ComponentExample>

### 只读
`readOnly` 会显示标签并保持输入框可聚焦，但无法添加或移除标签。与原生只读输入框一样，它会被表单校验跳过，即使设置了 `required`。

## 行为

按 Enter、逗号或 Tab 键即可创建标签。失去焦点同样会提交当前值。粘贴以逗号或换行分隔的文本时，会先将其插入光标处的文本中，然后同步创建各个值。粘贴不含分隔符的文本时，其行为与普通粘贴相同。重复的值会被忽略。

## 本地化

使用 `labels` 可以翻译标签输入框（TagInput）生成的所有文案：默认输入名称、标签移除操作、无效值提示和超限提示。

```tsx
<TagInput
  label="Etiquetas"
  labels={{
    input: "Agregar etiqueta",
    removeValue: (value) => `Eliminar ${value}`,
    invalidValue: (value) => `${value} no es valido.`,
    maxValuesReached: (maxValues) => `Maximo de ${maxValues} etiquetas.`,
  }}
/>
```
