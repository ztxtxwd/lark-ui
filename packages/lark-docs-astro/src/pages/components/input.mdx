## 用法

### 使用内置 Field（推荐）

<p>
  使用 `label` 属性可启用内置的 Field 包装器，获得标签、描述和错误提示支持。
</p>

```tsx
import { Input } from "@lark-ui/core";

export default function Example() {
  return (
    <Input
      label="Email"
      placeholder="you@example.com"
      description="We'll never share your email"
    />
  );
}
```

### 裸用 Input（自定义布局）

<p>
  在自定义表单布局中，请不要使用 `label`，直接使用 Input。出于无障碍考虑，必须提供 `aria-label` 或 `aria-labelledby`。
</p>

```tsx
import { Input } from "@lark-ui/core";

export default function Example() {
  return <Input placeholder="Search..." aria-label="Search products" />;
}
```
