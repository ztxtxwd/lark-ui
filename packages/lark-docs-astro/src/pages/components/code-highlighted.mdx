## 基本用法

  <p>
    用 `ShikiProvider` 包裹应用，只需配置一次 Shiki。
    其内部所有 `CodeHighlighted` 组件将共享同一个 Shiki 实例。
  </p>

```tsx
import { ShikiProvider, CodeHighlighted } from "@lark-ui/core/code";

export function App() {
  return (
    <ShikiProvider
      engine="javascript"
      languages={["tsx", "typescript", "bash", "json"]}
    >
      {/* All CodeHighlighted components share the same Shiki instance */}
      <CodeHighlighted code="const x = 1;" lang="typescript" />
    </ShikiProvider>
  );
}
```

## 服务端用法

  <p>
    对于 SSR 框架（Next.js RSC、Astro、Remix），请使用服务端工具在构建时完成高亮。
  </p>

#### 单次高亮

```tsx
// Next.js RSC or Astro
import { highlightCode } from "@lark-ui/core/code/server";

export default async function Page() {
  const html = await highlightCode(`const x = 1;`, "typescript");

  return <pre dangerouslySetInnerHTML={{ __html: html }} />;
}
```

#### 可复用的高亮器

```tsx
// For multiple highlights, reuse the highlighter
import { createServerHighlighter } from "@lark-ui/core/code/server";

const highlighter = await createServerHighlighter({
  languages: ["tsx", "bash", "json"],
});

const html1 = highlighter.highlight(code1, "tsx");
const html2 = highlighter.highlight(code2, "bash");

highlighter.dispose(); // Clean up when done
```

## 自定义 Hook

  <p>
    使用 `useShikiHighlighter` 实现自定义方案。
  </p>

```tsx
import { useShikiHighlighter } from "@lark-ui/core/code";

function CustomCodeBlock({ code, lang }) {
  const { highlight, isLoading, isReady, error } = useShikiHighlighter();

  if (error) {
    return <div className="text-red-500">Failed to load highlighter</div>;
  }

  if (isLoading) {
    return (
      <pre className="animate-pulse">
        <code>{code}</code>
      </pre>
    );
  }

  const html = highlight(code, lang);

  // null means highlighting failed — render plain text
  if (html === null) {
    return (
      <pre>
        <code>{code}</code>
      </pre>
    );
  }

  return <pre dangerouslySetInnerHTML={{ __html: html }} />;
}
```

## 框架集成

### Next.js App Router

```tsx
// app/providers.tsx
"use client";

import { ShikiProvider } from "@lark-ui/core/code";

export function Providers({ children }) {
  return (
    <ShikiProvider engine="javascript" languages={["tsx", "bash", "json"]}>
      {children}
    </ShikiProvider>
  );
}

// app/layout.tsx
import { Providers } from "./providers";

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

### Astro（静态）

<p>
  对于静态站点，使用服务端高亮即可实现零客户端 JavaScript。

```tsx
---
// src/components/CodeBlock.astro
import { highlightCode } from "@lark-ui/core/code/server";

const { code, lang } = Astro.props;
const html = await highlightCode(code, lang);
---

<div class="code-block" set:html={html} />
```

## 从 Code/CodeBlock 迁移

  <p>
    旧的 `Code` 和 `CodeBlock` 组件已废弃，将在 v2.0 中移除。
  </p>

```tsx
// Before (deprecated)
import { Code, CodeBlock } from "@lark-ui/core";
<CodeBlock code="const x = 1;" lang="ts" />

// After
import { ShikiProvider, CodeHighlighted } from "@lark-ui/core/code";

// Once at app root
<ShikiProvider engine="javascript" languages={["tsx"]}>
  <App />
</ShikiProvider>

// In components
<CodeHighlighted code="const x = 1;" lang="tsx" />
```
