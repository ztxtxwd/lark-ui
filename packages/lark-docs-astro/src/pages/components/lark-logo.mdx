## API 参考

<p>LarkLogo 继承自 <code>SVGSVGElement</code>，接受所有标准 SVG 属性。</p>

| 属性      | 类型                          | 默认值     | 说明                      |
| --------- | ----------------------------- | ---------- | ------------------------- |
| color     | `"color" \| "teal" \| "dark" \| "blue" \| "black" \| "white"` | `"color"` | 三色品牌标志，或指定单色处理。 |
| label     | `string`                      | -          | 无障碍标签。纯装饰用途时可省略。 |
| className | `string`                      | -          | 用于控制尺寸的 CSS 类名。 |
