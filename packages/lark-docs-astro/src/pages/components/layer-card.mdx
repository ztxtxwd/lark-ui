## 用法

```tsx
import { LayerCard } from "@lark-ui/core";

export default function Example() {
  return (
    <LayerCard className="w-[250px]">
      <LayerCard.Secondary>Documentation</LayerCard.Secondary>
      <LayerCard.Primary>Learn how to use Lark components</LayerCard.Primary>
    </LayerCard>
  );
}
```

<p>
  <code>LayerCard</code> 还支持简单的表面样式模式，适用于不需要次级标题行的场景。在这种情况下，请直接把内容渲染在 <code>LayerCard</code> 内部，而不要包裹在 <code>LayerCard.Primary</code> 中。
</p>

```tsx
import { LayerCard } from "@lark-ui/core";

export default function Example() {
  return (
    <LayerCard className="w-[250px] p-4">
      Learn how to use Lark components
    </LayerCard>
  );
}
```
