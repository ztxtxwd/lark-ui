## 用法

```tsx
import { Dialog, Button } from "@lark-ui/core";

export default function Example() {
  return (
    <Dialog.Root>
      <Dialog.Trigger render={(p) => <Button {...p}>Open</Button>} />
      <Dialog>
        <Dialog.Title>Dialog Title</Dialog.Title>
        <Dialog.Description>Dialog content goes here.</Dialog.Description>
        <div className="flex justify-end gap-2 mt-4">
          <Dialog.Close
            render={(p) => (
              <Button variant="secondary" {...p}>
                Cancel
              </Button>
            )}
          />
        </div>
      </Dialog>
    </Dialog.Root>
  );
}
```

## Dialog 与 Alert Dialog 的区别

<p>
  对话框（Dialog）组件支持两种 ARIA 角色，以便向辅助技术准确传达语义：
</p>

  <div class="overflow-hidden rounded-lg border border-lark-hairline">
    <table class="w-full text-sm">
      <thead class="bg-lark-elevated">
        <tr>
          <th class="px-4 py-3 text-left font-medium">角色</th>
          <th class="px-4 py-3 text-left font-medium">使用场景</th>
          <th class="px-4 py-3 text-left font-medium">行为</th>
        </tr>
      </thead>
      <tbody class="divide-y divide-lark-hairline">
        <tr>
          <td class="px-4 py-3">
            `role="dialog"`
            <span class="ml-2 text-lark-subtle">（默认）</span>
          </td>
          <td class="px-4 py-3">
            通用弹窗、表单、内容展示
          </td>
          <td class="px-4 py-3">默认可关闭</td>
        </tr>
        <tr>
          <td class="px-4 py-3">`role="alertdialog"`</td>
          <td class="px-4 py-3">
            破坏性操作、确认、关键警告
          </td>
          <td class="px-4 py-3">需要用户明确确认</td>
        </tr>
      </tbody>
    </table>

  `size` 属性控制对话框在桌面端的固定宽度。超出对话框宽度的内容会在对话框内部横向滚动，而不是撑宽对话框。

### 警告对话框（`role="alertdialog"`）

<p>
  对于破坏性操作或确认类对话框，请在 `Dialog.Root` 上使用 `role="alertdialog"`。这样对话框会以 `role="alertdialog"` 而不是 `role="dialog"` 渲染，提供正确的无障碍语义。
</p>
<div class="mb-4 rounded-lg border border-lark-info/30 bg-lark-info/10 p-4 text-sm text-lark-info">
  <p class="font-medium mb-2 text-sm">何时使用 `role="alertdialog"`：</p>
  <ul class="list-disc list-inside space-y-1 ml-2 mb-0">
    <li>破坏性操作（删除、丢弃、移除）</li>
    <li>需要用户明确确认的确认流程</li>
    <li>无法撤销的操作</li>
    <li>关键警告或错误</li>
  </ul>
</div>
<ComponentExample demo="DialogAlertDemo">
  <DialogAlertDemo client:load />
</ComponentExample>

### 确认对话框（配合 `disablePointerDismissal`）

<p>
  对于不希望点击外部即可关闭的确认对话框，请在 `Dialog.Root` 上使用 `disablePointerDismissal`。它可以与 `role="alertdialog"` 结合使用，以获得正确的无障碍效果。
