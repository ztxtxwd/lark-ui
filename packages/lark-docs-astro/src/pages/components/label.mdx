## 用法

### 与表单组件搭配使用（推荐）

  <p>
    通过 `Input`、`Select`、`Checkbox`、`Switch` 等表单组件的 `required` 和 `labelTooltip` 属性，可以直接使用标签（Label）的各项能力。
  </p>

```tsx
import { Input } from "@lark-ui/core";

export default function Example() {
  return (
    <>
      {/* Optional field with "(optional)" text */}
      <Input label="Phone" required={false} placeholder="+1 555-0000" />

      {/* With tooltip */}
      <Input
        label="API Key"
        labelTooltip="Find this in your dashboard settings"
      />
    </>
  );
}
```

### 独立使用 Label

<p>在自定义表单布局中，请直接使用 `Label` 组件。</p>

```tsx
import { Label } from "@lark-ui/core";

export default function Example() {
  return <Label tooltip="This field is mandatory">Username</Label>;
}
```

## 设计规范

  <div class="space-y-4 text-sm">
    <div>

      ### 何时使用可选标识

      <ul class="ml-4 list-disc space-y-1">
        <li>
          当大多数字段都是必填时，为可选字段标注"(optional)"
        </li>
        <li>同一个表单内保持一致</li>
        <li>默认字段（无标识）会被用户理解为必填</li>
      </ul>
    </div>
    <div>

      ### 何时使用工具提示

      <ul class="ml-4 list-disc space-y-1">
        <li>提供无法放进标签里的补充说明</li>
        <li>说明格式要求或校验规则</li>
        <li>为复杂字段提供帮助文档链接</li>
        <li>工具提示内容要简洁——最多 1-2 句话</li>
      </ul>
    </div>
    <div>

      ### 无障碍

      <ul class="ml-4 list-disc space-y-1">
        <li>
          可选标识仅用于视觉提示——校验请使用 `required` 属性
        </li>
        <li>工具提示可通过键盘聚焦信息图标来访问</li>
        <li>聚焦时，屏幕阅读器会播报工具提示内容</li>
      </ul>
    </div>
  </div>
</ComponentSection>
