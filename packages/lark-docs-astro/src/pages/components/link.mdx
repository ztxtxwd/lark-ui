## 用法

### 基础链接

  <p>
    默认的 Link 组件会渲染带下划线、使用主色样式的锚点元素。
  </p>

```tsx
import { Link } from "@lark-ui/core";

export default function Example() {
  return (
    <p>
      Read our <Link href="/docs">documentation</Link> for more details.
    </p>
  );
}
```

### 外部链接

<p>
  使用 `Link.ExternalIcon` 子组件来标识会在新标签页打开的链接。
</p>

```tsx
import { Link } from "@lark-ui/core";

export default function Example() {
  return (
    <Link
      href="https://cloudflare.com"
      target="_blank"
      rel="noopener noreferrer"
    >
      Visit Lark <Link.ExternalIcon />
    </Link>
  );
}
```

### 框架集成（LinkProvider）

<p>
  如需在全应用范围内接入路由，请在应用根节点配置 `LinkProvider`。你的包装组件会接收到 `href`，并负责把它桥接到路由的 API。这样工程师可以在任何地方使用 `<Link href="...">`，无需关心路由内部实现。
</p>

```tsx
import { forwardRef } from "react";
import { LinkProvider } from "@lark-ui/core";
import { Link as RouterLink } from "react-router-dom";

// Your app's wrapper maps href to the router's navigation prop
// and handles external URLs with a plain <a>
const AppLink = forwardRef(({ href, to, ...rest }, ref) => {
  const destination = href ?? to;
  const isExternal =
    destination?.startsWith("http") &&
    new URL(destination).origin !== window.location.origin;

  if (isExternal) {
    return <a ref={ref} href={destination} {...rest} />;
  }
  return <RouterLink ref={ref} to={destination} {...rest} />;
});

// Wrap your app once
export function App() {
  return (
    <LinkProvider component={AppLink}>
      {/* All <Link href="..."> calls go through AppLink */}
      <YourApp />
    </LinkProvider>
  );
}
```

### 使用 render 属性组合

<p>
  在需要直接控制渲染元素的特殊场景下，请使用 `render` 属性。它会完全绕过 `LinkProvider`——其余所有属性（`href`、`target`、`className` 等）都会自动合并到所提供的元素上。
</p>

```tsx
import { Link } from "@lark-ui/core";
import { Link as RouterLink } from "react-router-dom";

export default function Example() {
  return (
    <>
      {/* Force a specific router link (bypasses LinkProvider) */}
      <Link render={<RouterLink to="/dashboard" />} variant="inline">
        Dashboard
      </Link>

      {/* Force a plain anchor (bypasses LinkProvider) */}
      <Link render={<a />} href="https://example.com" target="_blank" rel="noopener noreferrer">
        External Site <Link.ExternalIcon />
      </Link>
    </>
  );
}
```

## 设计规范

  <div class="space-y-4 text-sm">
    <div>

      ### 各变体的适用场景

      <ul class="ml-4 list-disc space-y-1">
        <li>
          <strong>inline</strong>：正文文本中链接的默认选择
        </li>
        <li>
          <strong>current</strong>：告警栏、通告栏或其他带背景色容器中的链接
        </li>
        <li>
          <strong>plain</strong>：导航菜单、页脚，或不希望出现下划线的场景
        </li>
      </ul>
    </div>
    <div>

      ### 外链标识

      <ul class="ml-4 list-disc space-y-1">
        <li>对于在新标签页打开的链接，务必使用 `Link.ExternalIcon`</li>
        <li>
          出于安全考虑，设置 `target="_blank"` 和 `rel="noopener noreferrer"`
        </li>
        <li>
          该图标能直观提示用户将离开当前站点
        </li>
      </ul>
    </div>
    <div>

      ### 框架集成

      <ul class="ml-4 list-disc space-y-1">
        <li>
          在应用根节点配置 `LinkProvider`，以接入客户端路由
        </li>
        <li>
          你的包装组件会接收到 `href`，并将其映射到路由的导航属性（例如 React Router 的 `to`）
        </li>
        <li>
          包装组件应通过渲染普通的 `&lt;a&gt;` 来处理外部 URL，而不是走路由跳转
        </li>
        <li>
          在需要直接控制渲染元素的特殊场景下，可用 `render` 属性作为兜底方案
        </li>
        <li>
          `to` 属性已废弃——所有链接目标都请使用 `href`
        </li>
      </ul>
    </div>
    <div>

      ### 无障碍

      <ul class="ml-4 list-disc space-y-1">
        <li>链接默认可通过键盘聚焦</li>
        <li>
          外链图标带有 `aria-hidden="true"`——请为屏幕阅读器补充说明性文本
        </li>
        <li>确保所有变体都有足够的颜色对比度</li>
        <li>使用描述性的链接文案（避免"点击这里"这类表述）</li>
      </ul>
    </div>
  </div>
