```

import { Tabs } from "@lark-ui/core/components/tabs";
```

## 用法

```tsx
import { Tabs } from "@lark-ui/core";

export default function Example() {
  return (
    <Tabs
      tabs={[
        { value: "overview", label: "Overview" },
        { value: "settings", label: "Settings" },
      ]}
      selectedValue="overview"
    />
  );
}
```

## 示例

### 变体

#### 分段式（默认）

<p>
  胶囊形状的指示器在浅色背景上于各标签页之间滑动。轨道默认贴合标签文字宽度；
  需要让控件填满固定宽度的容器（表单行、气泡卡片、工具栏）时，加上 `fill`，
  各标签页会等分整条轨道。
</p>
<ComponentExample demo="TabsSegmentedDemo">
  <TabsSegmentedDemo client:visible />
</ComponentExample>

#### 下划线式

<p>
  底部边框配合主色指示器。当前标签页的文字更粗，以突出显示。
</p>
<ComponentExample demo="TabsUnderlineDemo">
  <TabsUnderlineDemo client:visible />
</ComponentExample>

### 小尺寸

<p>
  使用 `size="sm"` 可获得与 `Input size="sm"` 高度一致（h-6.5 / 26px）的紧凑标签栏。
  适合放在工具栏（Toolbar）和筛选行中。
</p>
<ComponentExample demo="TabsSmDemo">
  <TabsSmDemo client:visible />
</ComponentExample>

### 撑满轨道（fill）

<p>
  默认状态下分段式轨道只占标签文字所需的宽度——否则在块级容器里会拉出一条
  右侧留空的灰色轨道。`fill` 让轨道撑满父容器，并让每个标签页等分宽度；
  标签文字过长时不会挤压，而是由标签栏横向滚动。
</p>
<ComponentExample demo="TabsFillDemo">
  <TabsFillDemo client:visible />
</ComponentExample>

### 受控

<p>使用 `value` 和 `onValueChange` 属性来控制受控状态。</p>
<ComponentExample demo="TabsControlledDemo">
  <TabsControlledDemo client:visible />
</ComponentExample>

### 标签页过多

<p>当条目较多时，标签页会自动横向滚动。</p>
<ComponentExample demo="TabsManyDemo">
  <TabsManyDemo client:visible />
</ComponentExample>

### 横向溢出

<p>
  当分段式标签页超出容器时，被裁剪的一侧会出现滚动按钮。
  你可以使用这些按钮、横向滚动或鼠标拖拽来查看屏幕之外的标签页。
</p>
<ComponentExample demo="TabsOverflowDemo">
  <TabsOverflowDemo client:visible />
</ComponentExample>

### 动态标签数量

<p>
  此示例会在溢出的标签集合与接近生产的七标签页集合之间切换。
  当多余标签消失后，只要剩余标签能够放下，末尾的溢出控件就应隐藏。
</p>
<ComponentExample demo="TabsDynamicCountDemo">
  <TabsDynamicCountDemo client:visible />
</ComponentExample>
