## 用法

```tsx
import { Radio } from "@lark-ui/core";

export default function Example() {
  return (
    <Radio.Group legend="Choose an option" defaultValue="a">
      <Radio.Item label="Option A" value="a" />
      <Radio.Item label="Option B" value="b" />
    </Radio.Group>
  );
}
```

#### 是否应该使用分段样式？
仅当分组较小、标签简短且控件能放下一行时，才使用分段样式。标签较长、需要描述性选项、选项数量较多或布局较窄时，请使用默认样式。

当选择结果决定显示哪个内容面板时，请使用 [标签页（Tabs）](/components/tabs) 组件。

<p>
  `Radio.Group` 和 `Radio.Item` 支持泛型。传入类型参数（例如 `<number>` 或枚举类型），可以

  省略时默认为 `string`。
</p>
