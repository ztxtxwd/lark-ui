## 用法

```tsx
import { useState } from "react";
import { Pagination } from "@lark-ui/core";

export default function Example() {
  const [page, setPage] = useState(1);

  return (
    <Pagination page={page} setPage={setPage} perPage={10} totalCount={100} />
  );
}
```

### 未知总数

<p>
  当数据源不返回总数时，请使用 `hasNextPage`。这在基于游标的 API 中很常见，因为计算总数
  可能代价高昂或根本无法获取。请根据响应中的「还有下一页」信号来设置它，使「下一页」按钮
  仅在仍存在后续结果集时保持可用。
</p>
<p>
  没有总数时，用户只能顺序翻页，因此分页（Pagination）会隐藏首页、末页和页码选择器控件。
  `page` 值对界面仍然有用，但每次请求的游标或续传令牌需要由你的应用负责存储和发送。
</p>

```tsx
const [page, setPage] = useState(1);
const { data } = useQuery({
  queryKey: ["events", page],
  queryFn: () => getEvents({ cursor: cursors[page - 1] }),
});

return (
  <Pagination
    page={page}
    setPage={setPage}
    hasNextPage={data.hasMore}
    text={() => `Page ${page}`}
  />
);
```

### 空结果

<p>
  当 `totalCount={0}` 时，分页会显示一个空页面，且 `setPage` 永远不会被调用为第 0 页。
  在第 1 页时，所有导航按钮均为禁用状态。如果在较后面的页面（例如筛选之后）结果可能变为空，
  请将 `page` 重置为 1。
</p>
<ComponentExample demo="PaginationEmptyDemo">
  <PaginationEmptyDemo client:visible />
</ComponentExample>

### 页码输入框

<p>
  页码输入框只接受整数页码。按回车或将焦点移开即可跳转到该页。超出范围的数字会跳到首页或末页。
  其他内容（如 `abc`、`2.5` 或 `1e1`）会恢复当前页，并且不会调用 `setPage`。
</p>

### 下拉式页码选择器

    <p>
      在 `Pagination.Controls` 上使用 `pageSelector="dropdown"`，可以用下拉选择器代替文本输入框
      进行页码导航。当你希望用户从可用页面列表中选择，而不是手动输入数字时，这会非常有用。
    </p>
    <ComponentExample
      code={`<Pagination page={page} setPage={setPage} perPage={perPage} totalCount={500}>

  <Pagination.Info />
  <Pagination.Separator />
  <Pagination.PageSize
    value={perPage}
    onChange={(size) => {
      setPerPage(size);
      setPage(1);
    }}
  />
  <Pagination.Controls pageSelector="dropdown" />
</Pagination>`}
