## 用法

### 使用内置 Field（推荐）

<p>
  为 InputGroup 传入 `label` 属性可启用内置的 Field 包装器，获得标签、描述和错误提示支持。
</p>

```tsx
import { InputGroup } from "@lark-ui/core";
import { MagnifyingGlassIcon } from "@phosphor-icons/react";

export default function Example() {
  return (
    <InputGroup label="Search" description="Find pages, components, and more">
      <InputGroup.Addon>
        <MagnifyingGlassIcon />
      </InputGroup.Addon>
      <InputGroup.Input placeholder="Search..." />
    </InputGroup>
  );
}
```

### 裸用 InputGroup（自定义布局）

<p>
  在自定义表单布局中，请不要使用 `label`，直接使用 InputGroup。出于无障碍考虑，必须在 `InputGroup.Input` 上提供 `aria-label`。
</p>

```tsx
import { InputGroup } from "@lark-ui/core";
import { MagnifyingGlassIcon } from "@phosphor-icons/react";

export default function Example() {
  return (
    <InputGroup>
      <InputGroup.Addon>
        <MagnifyingGlassIcon />
      </InputGroup.Addon>
      <InputGroup.Input placeholder="Search..." aria-label="Search" />
    </InputGroup>
  );
}
```

## API 参考

### `InputGroup`

<p>
  为所有子组件提供上下文的根容器。接受 Field 属性（`label`、`description`、`error`），在提供 label 时会用 Field 包裹内容。
</p>
<PropsTable component="InputGroup" />

### `InputGroup.Input`

<p>
  文本输入元素。从 InputGroup 上下文继承 `size`、`disabled` 和 `error`。接受所有标准 input 属性，但与 Field 相关的属性除外（由父组件处理）。
</p>
<PropsTable component="InputGroup.Input" />

### `InputGroup.Addon`

<p>
  位于输入框起始或末尾的容器，用于放置图标、文本或紧凑按钮。
</p>
<PropsTable component="InputGroup.Addon" />

### `InputGroup.Button`

<p>
  用于切换、复制、帮助等次要操作的按钮。渲染在 Addon 内部。传入 `tooltip` 属性即可在悬停时显示工具提示。
</p>
<PropsTable component="InputGroup.Button" />

### `InputGroup.Suffix`

<p>
  与输入内容自然衔接的行内文本（例如 `.workers.dev`）。输入框宽度会随着用户输入自动调整。
</p>
<PropsTable component="InputGroup.Suffix" />

## 无障碍

  <div class="space-y-4 text-sm">
    <div>

      ### 标签要求

      <p>
        InputGroup 需要通过以下方式之一获得无障碍名称：
      </p>
      <ul class="mt-2 ml-4 list-disc space-y-1">
        <li>
          InputGroup 上的 `label` 属性（渲染可见标签，并支持内置 Field）
        </li>
        <li>
          没有可见标签时，在 InputGroup.Input 上使用 `aria-label`
        </li>
        <li>
          自定义标签关联时，在 InputGroup.Input 上使用 `aria-labelledby`
        </li>
      </ul>
      <p class="mt-2">
        缺少无障碍名称会在开发模式下触发控制台警告。
      </p>
    </div>
    <div>

      ### 分组角色

      <p>
        InputGroup 会自动以 `role="group"` 渲染，在语义上将输入框与其附加内容关联起来，便于辅助技术识别。
      </p>
    </div>

  </div>
