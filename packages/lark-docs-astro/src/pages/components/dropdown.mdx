## 用法

```tsx
import { DropdownMenu, Button } from "@lark-ui/core";

export default function Example() {
  return (
    <DropdownMenu>
      <DropdownMenu.Trigger render={<Button>Menu</Button>} />
      <DropdownMenu.Content>
        <DropdownMenu.Item onClick={() => console.log("edit")}>
          Edit
        </DropdownMenu.Item>
        <DropdownMenu.Item onClick={() => console.log("duplicate")}>
          Duplicate
        </DropdownMenu.Item>
        <DropdownMenu.Separator />
        <DropdownMenu.Item
          variant="danger"
          onClick={() => console.log("delete")}
        >
          Delete
        </DropdownMenu.Item>
      </DropdownMenu.Content>
    </DropdownMenu>
  );
}
```

## API 参考

### DropdownMenu

<p>管理下拉菜单状态的根组件。</p>
<PropsTable component="DropdownMenu" />

### DropdownMenu.Trigger

<p>点击时打开下拉菜单的按钮。</p>
<PropsTable component="DropdownMenu.Trigger" />

### DropdownMenu.Content

<p>
  菜单弹层。由 `Portal`、`Positioner` 和 `Popup` 组合而成：`side`、`align`、`sideOffset`、`alignOffset` 等定位属性作用于 Positioner，`className` 作用于 Popup。
</p>
<PropsTable component="DropdownMenu.Content" />

### DropdownMenu.Portal、Positioner 和 Popup

<p>
  组成 `Content` 的各个部件。当你需要分别设置 Positioner 和 Popup 的样式或配置时，可以直接组合它们。`Portal` 会遵循 `LarkPortalProvider` 的设置，`Popup` 则承载菜单的表面样式和展开/收起动画。
</p>

```tsx
<DropdownMenu.Portal>
  <DropdownMenu.Positioner side="top" align="end">
    <DropdownMenu.Popup className="min-w-56">
      <DropdownMenu.Item>Edit</DropdownMenu.Item>
    </DropdownMenu.Popup>
  </DropdownMenu.Positioner>
</DropdownMenu.Portal>
```

<p>
  两者接受的属性与 Base UI 的 `Menu.Positioner` 和 `Menu.Popup` 相同。完整列表请参阅 [Base UI Menu 文档](https://base-ui.com/react/components/menu)。
</p>

### DropdownMenu.Item

<p>用于执行操作的单个菜单项。</p>
<PropsTable component="DropdownMenu.Item" />

### DropdownMenu.LinkItem

<p>
  跳转到 URL 的菜单项。渲染语义化的 `<a>` 元素。导航链接请使用它而不是 `Item`。
</p>
<PropsTable component="DropdownMenu.LinkItem" />

### DropdownMenu.CheckboxItem

<p>
  可切换开关状态的菜单项。适用于相互独立的布尔选项。
</p>
<PropsTable component="DropdownMenu.CheckboxItem" />

### DropdownMenu.Sub

<p>
  嵌套子菜单的根组件。请将 SubTrigger 和 SubContent 包裹在其中。
</p>
<PropsTable component="DropdownMenu.Sub" />

### DropdownMenu.SubTrigger

<p>
  悬停或点击时打开嵌套子菜单的菜单项。会自动显示一个箭头图标，并在子菜单展开时保持高亮。与 `Item` 一样，它的 `icon` 属性接受 Phosphor 图标组件或已渲染的元素。
</p>
<PropsTable component="DropdownMenu.SubTrigger" />

### DropdownMenu.SubContent

<p>
  子菜单项的容器。相对于 SubTrigger 定位。当子菜单位于触发器旁边时，会取消弹层内边距，使第一项与触发器对齐并略微覆盖父菜单。若空间不足而移动到触发器上方或下方，则使用与顶级菜单相同的间距。可通过 `sideOffset` 或 `alignOffset`（数字，或根据最终 `side` 计算的函数）覆盖该行为。
</p>
<PropsTable component="DropdownMenu.SubContent" />

### DropdownMenu.Separator

<p>菜单项之间的视觉分隔线。</p>
<PropsTable component="DropdownMenu.Separator" />

### DropdownMenu.RadioGroup

<p>
  将单选项组织成一组，实现单选行为。同一时间只能选中一项。

<PropsTable component="DropdownMenu.RadioGroup" />

### DropdownMenu.RadioItem

<PropsTable component="DropdownMenu.RadioItem" />
