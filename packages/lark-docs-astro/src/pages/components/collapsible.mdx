## 用法

Collapsible 采用复合组件模式，便于完全掌控组合方式。

### 使用默认样式

使用 `DefaultTrigger` 和 `DefaultPanel` 可获得经典的 Lark 样式：

```tsx
import { Collapsible } from "@lark-ui/core";

export default function Example() {
  const [open, setOpen] = useState(false);

  return (
    <Collapsible.Root open={open} onOpenChange={setOpen}>
      <Collapsible.DefaultTrigger>Show details</Collapsible.DefaultTrigger>
      <Collapsible.DefaultPanel>
        Content with border-left accent styling.
      </Collapsible.DefaultPanel>
    </Collapsible.Root>
  );
}
```

### 自定义触发器

在 `Trigger` 上使用 `render` 属性，可完全控制触发元素：

```tsx
<Collapsible.Root open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger render={<Button variant="ghost" />}>
    {open ? "Hide" : "Show"} details
  </Collapsible.Trigger>
  <Collapsible.Panel className="mt-2 p-4 bg-lark-tint rounded-lg">
    Custom styled panel content.
  </Collapsible.Panel>
</Collapsible.Root>
```

## 子组件

| 组件 | 描述 |
|-----------|-------------|
| `Collapsible.Root` | 管理展开状态。传入 `open` 和 `onOpenChange` 可使用受控模式。 |
| `Collapsible.Trigger` | 切换显示状态的按钮。使用 `render` 属性可替换为自定义元素。 |
| `Collapsible.Panel` | 可折叠内容的容器。 |
| `Collapsible.DefaultTrigger` | 预置样式的触发器，带文字标签和带动画的箭头图标。 |
| `Collapsible.DefaultPanel` | 预置样式的面板，带左侧强调边框和标准间距。 |

</ComponentSection>

## API 参考

### Collapsible.Root

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `open` | `boolean` | — | 面板是否可见（受控）。 |
| `defaultOpen` | `boolean` | `false` | 初始展开状态（非受控）。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化时的回调。 |
| `disabled` | `boolean` | `false` | 折叠面板是否禁用。 |

### Collapsible.Trigger

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `render` | `ReactElement` | — | 作为触发器渲染的自定义元素。 |
| `className` | `string` | — | 附加的 CSS 类名。 |

### Collapsible.Panel

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `className` | `string` | — | 附加的 CSS 类名。 |
| `keepMounted` | `boolean` | `false` | 关闭时是否将面板保留在 DOM 中。 |

### Collapsible.DefaultTrigger

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | 触发器中显示的标签文字。 |
| `className` | `string` | — | 附加的 CSS 类名。 |

### Collapsible.DefaultPanel

除下列属性外，还接受 `Collapsible.Panel` 的全部属性。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | 面板内容。 |
| `className` | `string` | — | 附加的 CSS 类名。 |
| `keepMounted` | `boolean` | `false` | 关闭时是否将面板保留在 DOM 中。 |
