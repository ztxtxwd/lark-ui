## 用法

```tsx
import { Popover, Button } from "@lark-ui/core";

export default function Example() {
  return (
    <Popover.Root>
      <Popover.Trigger render={<Button />}>Open</Popover.Trigger>
      <Popover.Portal>
        <Popover.Positioner>
          <Popover.Popup>
            <Popover.Arrow />
            <Popover.Title>Popover Title</Popover.Title>
            <Popover.Description>Popover content goes here.</Popover.Description>
          </Popover.Popup>
        </Popover.Positioner>
      </Popover.Portal>
    </Popover.Root>
  );
}
```

### 已弃用的 Popover.Content 兼容性

<p>
  `Popover.Content` 已被弃用，但仍然保留，以免现有气泡卡片失效。它把 `Portal`、`Positioner`、
  `Popup` 和 `Arrow` 合并为一个组件，并且仅通过不透明度实现平滑淡入，不带缩放或位移动画。
  新的气泡卡片应像基础示例中那样组合各个独立部分。
</p>
<ComponentExample demo="PopoverLegacyContentDemo">
  <PopoverLegacyContentDemo client:load />
</ComponentExample>

### 可滚动内容

<p>
  当箭头和标题需要保持固定时，请把溢出的内容放在内部滚动容器中。已弃用的 `Popover.Content`
  上现有的溢出样式仍然受支持，因为它只使用淡入淡出过渡。
</p>

### 虚拟锚点

<p>
  在 `Popover.Positioner` 上使用 `anchor` 属性，可以让气泡卡片相对触发元素之外的元素定位，
  或相对一个虚拟点（例如 `getBoundingClientRect()` 返回的 `DOMRect`）定位。当触发元素和期望的
  锚点位于不同的组件树中时，这会非常有用。

## API 参考

### Popover.Root

<p>管理气泡卡片打开状态的根组件。</p>
<PropsTable component="Popover" />

### Popover.Trigger

<p>
  点击时打开气泡卡片的按钮。使用 `render` 可渲染你自己的元素。
</p>
<PropsTable component="Popover.Trigger" />

### Popover.Portal

<p>
  在应用的 DOM 层级之外渲染气泡卡片。默认使用 `LarkPortalProvider` 提供的容器，也可以通过
  `container` 属性覆盖。
</p>
<PropsTable component="Popover.Portal" />

### Popover.Backdrop

<p>渲染在气泡卡片后方的可选遮罩层。</p>
<PropsTable component="Popover.Backdrop" />

### Popover.Positioner

<p>
  相对触发元素或 `anchor` 定位弹层。使用 `side`、`align` 及其偏移量属性来控制位置。
</p>
<PropsTable component="Popover.Positioner" />

### Popover.Popup

<p>
  带样式的弹层容器。请将 `Popover.Arrow` 和气泡卡片内容直接放在其中。
</p>
<PropsTable component="Popover.Popup" />

### Popover.Arrow

<p>指向气泡卡片锚点的可选箭头。</p>
<PropsTable component="Popover.Arrow" />

### Popover.Viewport

<p>
  当同一个弹层由多个触发元素共享时，用于为内容切换添加动画的视口。普通气泡卡片或滚动内容
  不需要它。
</p>
<PropsTable component="Popover.Viewport" />

### Popover.Content

<p>
  已弃用的兼容包装组件，合并了 `Portal`、`Positioner`、`Popup` 和 `Arrow`。现有用法仍然
  受支持，但新代码应组合上面展示的各个独立部分。
</p>
<PropsTable component="Popover.Content" />

### Popover.Title

<p>为气泡卡片提供标签的标题，用于无障碍。</p>
<PropsTable component="Popover.Title" />

### Popover.Description

<p>为气泡卡片内容提供补充说明的段落。</p>
<PropsTable component="Popover.Description" />

### Popover.Close

<p>
  点击时关闭气泡卡片的按钮。使用 `render` 可渲染你自己的元素。
</p>
<PropsTable component="Popover.Close" />
