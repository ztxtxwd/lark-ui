## 安装

### 统一导出

```tsx
import { Badge } from "@lark-ui/core";
```

### 按需导出

```tsx
import { Badge } from "@lark-ui/core/components/badge";
```

## 用法

```tsx
import { Badge } from "@lark-ui/core";

export default function Example() {
  return <Badge variant="secondary">New</Badge>;
}
```

### 其他颜色变体

### 圆点徽标

使用 `appearance="dot"` 可以得到带彩色圆点的轻量状态指示器。支持 `success`、`warning`、`error` 和 `neutral` 变体。

<ComponentExample demo="BadgeDotDemo">
  <BadgeDotDemo client:visible />
</ComponentExample>

### 带图标

实心徽标可通过 `icon` 接收 Phosphor 图标组件或 React 元素。圆点徽标使用自身的状态圆点，不接受图标。

<ComponentExample demo="BadgeIconDemo">
  <BadgeIconDemo client:visible />
</ComponentExample>

### 链接徽标

用 [`Link`](/components/link) 包裹徽标使其可导航。当上级链接被悬停时，徽标会显示一圈描边。
