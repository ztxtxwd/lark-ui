{/* Filtering */}

<ComponentSection>

## 过滤

<p>
  默认情况下，过滤不区分大小写和重音符号，底层由 `Intl.Collator` 提供支持。对于字符串选项，无需自定义 `filter`。
</p>
<p>
  当需要按对象选项的某个属性进行过滤时，请使用
  `Autocomplete.useFilter()` 以保留内置的不区分重音符号的匹配能力：
</p>

```tsx
function LanguagePicker() {
  const { contains } = Autocomplete.useFilter();

  const filter = useCallback(
    (item: Language, query: string) => contains(item.label, query),
    [contains],
  );

  return (
    <Autocomplete items={languages} filter={filter}>
      {/* ... */}
    </Autocomplete>
  );
}
```

<p>
  如需完全关闭过滤（例如结果来自服务端），传入 `filter={null}`：
</p>

```tsx
<Autocomplete items={results} filter={null}>
  ...
</Autocomplete>
```
