## 用法

```tsx
import { Banner } from "@lark-ui/core";
import { Info } from "@phosphor-icons/react";

export default function Example() {
  return (
    <Banner
      icon={<Info weight="fill" />}
      title="Update available"
      description="A new version is ready to install."
    />
  );
}
```

### 紧凑尺寸

在对话框等空间受限的场景中使用 `size="sm"`。此时通告栏应服务于周边体验，不与主要操作争夺注意力，因此优先使用与描述文字行内渲染的 Lark `Link`。需要更强强调时，请使用 `Banner.Action`，它会渲染在末尾位置。
