## 用法

  <p>
    流程图（Flow）组件组合使用可以创建有向流程图。使用
    `Flow` 作为容器，用
    `Flow.Node` 表示单个步骤，用
    `Flow.Parallel` 创建分支路径。
  </p>

```tsx
import { Flow } from "@lark-ui/core";

export default function Example() {
  return (
    <Flow>
      <Flow.Node>Step 1</Flow.Node>
      <Flow.Node>Step 2</Flow.Node>
      <Flow.Node>Step 3</Flow.Node>
    </Flow>
  );
}
```

  设置 `orientation="vertical"` 可让节点自上而下排列，而不是默认的从左到右。连接线、并行分支和 `align` 都会适配垂直方向。

<p>

### 自定义锚点

<p>
  默认情况下，连接线连接到每个节点的中心。使用 `Flow.Anchor` 及其 `render` 属性可以指定自定义的连接点。`type` 属性决定锚点是作为 `"start"` 点（连接线出发处）还是 `"end"` 点（连接线到达处）。
</p>
<ComponentExample demo="FlowAnchorDemo">
  <FlowAnchorDemo client:visible />
</ComponentExample>

### 平移大型图表

<p>
  当图表超出容器范围时，Flow 会自动启用平移。可以拖动来平移视口，也可以使用滚轮。悬停时会出现滚动条，指示可滚动的区域。
</p>

### 禁用节点

<p>
  在节点上使用 `disabled` 属性，以视觉方式表明其处于未激活状态。连接到禁用节点的连线会以降低的不透明度渲染。
</p>

    `"end"` 右对齐。
