## 用法

  <p>
    CommandPalette 是基于 Base UI 的 Autocomplete 原语构建的复合组件。它为命令面板界面提供无障碍的键盘导航和可自定义的样式。
  </p>

```tsx
import { useState } from "react";
import { CommandPalette } from "@lark-ui/core";

interface Item {
  id: string;
  title: string;
}

const items: Item[] = [
  { id: "1", title: "Create Project" },
  { id: "2", title: "Open Settings" },
];

export default function Example() {
  const [open, setOpen] = useState(false);
  const [search, setSearch] = useState("");

  return (
    <>
      <button onClick={() => setOpen(true)}>Open</button>
      <CommandPalette.Root
        open={open}
        onOpenChange={setOpen}
        items={items}
        value={search}
        onValueChange={setSearch}
        itemToStringValue={(item) => item.title}
        getSelectableItems={(items) => items}
      >
        <CommandPalette.Input placeholder="Search..." />
        <CommandPalette.List>
          <CommandPalette.Results>
            {(item) => (
              <CommandPalette.Item
                key={item.id}
                value={item}
                onClick={() => setOpen(false)}
              >
                {item.title}
              </CommandPalette.Item>
            )}
          </CommandPalette.Results>
          <CommandPalette.Empty>No results</CommandPalette.Empty>
        </CommandPalette.List>
      </CommandPalette.Root>
    </>
  );
}
```

## 组件构成

### CommandPalette.Root

<p>
  组合 Dialog 与 Panel 的主容器。管理打开状态和自动补全（Autocomplete）功能。
</p>

### CommandPalette.Dialog

<p>
  模态弹层容器。与 Panel 搭配使用可切换内容（例如逐级下钻导航）。
</p>

### CommandPalette.Panel

<p>
  不含弹层的自动补全面板。放在 Dialog 内使用，可切换内容而无需重新挂载。
</p>

### CommandPalette.Input

<p>带自动聚焦和键盘处理的搜索输入框。</p>

### CommandPalette.List

<p>结果的可滚动容器。</p>

### CommandPalette.Results

<p>用于遍历选项／分组的 render 属性迭代器。</p>

### CommandPalette.Group

<p>按类别分组的容器。</p>

### CommandPalette.GroupLabel

<p>分组内的区块标题文字。</p>

### CommandPalette.Items

<p>用于遍历分组内选项的 render 属性迭代器。</p>

### CommandPalette.Item

<p>基础可选项。</p>

### CommandPalette.ResultItem

<p>包含面包屑、图标和文本高亮的富内容选项。</p>

### CommandPalette.HighlightedText

<p>根据匹配位置渲染带高亮片段的文本。</p>

### CommandPalette.Empty

<p>没有匹配结果时的空状态。</p>

### CommandPalette.Loading

<p>加载动画状态。</p>

### CommandPalette.Footer

  <p>
    用于放置快捷键提示或其他内容的底部区域。
  </p>

## API 参考

### CommandPalette.Root 属性

```tsx
interface CommandPaletteRootProps<TGroup, TItem> {
  // Dialog state
  open: boolean;
  onOpenChange: (open: boolean) => void;
  onBackdropClick?: (e: React.MouseEvent) => void;

  // Autocomplete
  items: TGroup[];
  value?: string;
  onValueChange?: (value: string) => void;
  itemToStringValue?: (item: TGroup) => string;
  filter?: (item: TGroup, query: string) => boolean;
  onItemHighlighted?: (item: TGroup | undefined, details: {...}) => void;

  // Selection
  onSelect?: (item: TItem, options: { newTab: boolean }) => void;
  getSelectableItems?: (items: TGroup[]) => TItem[];

  children: React.ReactNode;
}
```

### CommandPalette.ResultItem 属性

```tsx
interface CommandPaletteResultItemProps<T> {
  value: T;
  title: string;
  breadcrumbs?: string[];
  titleHighlights?: [number, number][];
  breadcrumbHighlights?: [number, number][][];
  description?: string;
  icon?: React.ReactNode;
  onClick: (e: React.MouseEvent) => void;
  showArrow?: boolean; // default: true
  external?: boolean; // shows external link icon
  nonInteractive?: boolean;
}
```
