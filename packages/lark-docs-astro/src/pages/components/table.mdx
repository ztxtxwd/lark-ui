## 示例

### 带复选框

<p>
  使用 `Table.CheckHead` 和 `Table.CheckCell` 添加行选择。两者都接受
  `onCheckedChange`，其签名与底层 `Checkbox`（复选框）组件一致，并通过第二个参数提供可选的事件详情。
</p>
<p>
  较早的 `onValueChange` 属性仍然可用，但已被弃用——lint 规则会对其标记警告，并将在未来的主版本中移除。请通过重命名该属性完成迁移：
</p>

```tsx
// Before (deprecated)
<Table.CheckCell onValueChange={(checked) => toggleRow(id)} />

// After
<Table.CheckCell onCheckedChange={(checked) => toggleRow(id)} />

// With event details
<Table.CheckCell
  onCheckedChange={(checked, eventDetails) => {
    toggleRow(id);
    eventDetails?.event.stopPropagation();
  }}
/>
```

## API 参考

### Table

<p>根表格组件。渲染语义化的 `<table>` 元素。</p>
<PropsTable component="Table" />

### Table.Header

<p>表头区域。渲染 `<thead>`。设置 `sticky` 可将表头行固定在滚动容器顶部。</p>

### Table.Body

<p>表体区域。渲染 `<tbody>`。</p>

### Table.Row

<p>表格行。支持 `variant="selected"` 以高亮显示。</p>
<PropsTable component="Table.Row" />

### Table.Head

<p>表头单元格。渲染 `<th>`。接受 `sticky="left"` 或 `sticky="right"` 来固定该列。</p>

### Table.Cell

<p>表体单元格。渲染 `<td>`。接受 `sticky="left"` 或 `sticky="right"` 来固定该列。</p>

### Table.CheckHead

<p>带复选框的表头单元格，用于「全选」功能。</p>
<PropsTable component="Table.CheckHead" />

### Table.CheckCell

<p>带复选框的表体单元格，用于行选择。</p>
<PropsTable component="Table.CheckCell" />

### Table.ResizeHandle

<p>
  用于调整列宽的可拖拽手柄。可配合 TanStack Table 或自定义的调整逻辑使用。
</p>

## TanStack Table 集成

  <p>
    如需排序、筛选和可调整列宽等高级功能，请集成 <a href="https://tanstack.com/table" class="text-lark-link hover:underline" target="_blank" rel="noopener noreferrer">TanStack Table</a>。表格（Table）组件经过专门设计，可与 TanStack 的无头 API 无缝协作。
  </p>

```tsx
import {
  flexRender,
  getCoreRowModel,
  useReactTable,
} from "@tanstack/react-table";
import { Table } from "@lark-ui/core";

function DataTable({ data, columns }) {
  const table = useReactTable({
    data,
    columns,
    getCoreRowModel: getCoreRowModel(),
    columnResizeMode: "onChange",
  });

  return (
    <Table layout="fixed">
      <colgroup>
        {table.getAllColumns().map((column) => (
          <col key={column.id} style={{ width: column.getSize() }} />
        ))}
      </colgroup>
      <Table.Header>
        {table.getHeaderGroups().map((headerGroup) => (
          <Table.Row key={headerGroup.id}>
            {headerGroup.headers.map((header) => (
              <Table.Head key={header.id}>
                {flexRender(
                  header.column.columnDef.header,
                  header.getContext(),
                )}
                <Table.ResizeHandle
                  onMouseDown={header.getResizeHandler()}
                  onTouchStart={header.getResizeHandler()}
                />
              </Table.Head>
            ))}
          </Table.Row>
        ))}
      </Table.Header>
      <Table.Body>
        {table.getRowModel().rows.map((row) => (
          <Table.Row key={row.id}>
            {row.getVisibleCells().map((cell) => (
              <Table.Cell key={cell.id}>
                {flexRender(cell.column.columnDef.cell, cell.getContext())}
              </Table.Cell>
            ))}
          </Table.Row>
        ))}
      </Table.Body>
    </Table>
  );
}
```
