## 用法

```tsx
import { Switch } from "@lark-ui/core";
import { useState } from "react";

export default function Example() {
  const [checked, setChecked] = useState(false);

  return (
    <Switch checked={checked} onCheckedChange={(val) => setChecked(val)} />
  );
}
```

### 变体

<p>
  开关（Switch）支持两种变体：`default`（开启时为蓝色）和 `neutral`（单色）。两者都使用
  超椭圆（squircle）形状。
</p>

  <SwitchVariantsDemo client:visible />
</ComponentExample>

### 中性变体

<p>
  中性变体使用单色配色和超椭圆形状，适合低调、不突出的切换控件。
</p>

  <SwitchNeutralDemo client:visible />

  <SwitchSizesDemo client:visible />

### 自定义 ID

<p>
  提供自定义 `id` 后，点击标签仍会切换开关状态。该 `id` 会透传给 Base UI，使标签的
  `htmlFor` 保持同步。
</p>
<ComponentExample demo="SwitchCustomIdDemo">
  <SwitchCustomIdDemo client:visible />
</ComponentExample>

### 开关组

<p>
  使用 `Switch.Group` 可以对相关开关进行分组，并为分组提供共享的图例（legend）、描述和
  错误信息。
</p>
<ComponentExample demo="SwitchGroupDemo">
  <SwitchGroupDemo client:visible />
</ComponentExample>

### 视觉隐藏的图例

<p>
  在 `Switch.Legend` 上使用 `className="sr-only"`，可以让图例对屏幕阅读器保持可访问，同时在
  视觉上隐藏。当分组已经由父级 `Field` 或标题标注，显示图例会造成标签重复时，这会非常有用。
</p>
<ComponentExample demo="SwitchLegendSrOnlyDemo">
  <SwitchLegendSrOnlyDemo client:visible />
</ComponentExample>

### 自定义图例样式

<p>
  `Switch.Legend` 接受 `className`，可完全控制图例的呈现方式。当需要自定义排版、颜色或布局时，
  请使用它代替 `legend` 字符串属性。
</p>
