## 用法

### 使用内置 Field（推荐）

<p>
  使用 `label` 属性可启用内置的 Field 包装器，获得标签、描述和错误提示支持。
</p>

```tsx
import { InputArea } from "@lark-ui/core";

export default function Example() {
  return (
    <InputArea
      label="Description"
      placeholder="Enter a description..."
      description="Provide details about your project"
    />
  );
}
```

### 裸用 InputArea（自定义布局）

<p>
  在自定义表单布局中，请不要使用 `label`，直接使用 InputArea。出于无障碍考虑，必须提供 `aria-label` 或 `aria-labelledby`。
</p>

```tsx
import { InputArea } from "@lark-ui/core";

export default function Example() {
  return <InputArea placeholder="Add notes..." aria-label="Notes" rows={3} />;
}
```

## 无障碍

### 标签要求

<p>InputArea 需要通过以下方式之一获得无障碍名称：</p>

<ul class="ml-4 list-disc space-y-1">
  <li>`label` 属性（推荐）</li>
  <li>裸文本域使用 `placeholder` + `aria-label`</li>
  <li>自定义标签关联使用 `aria-labelledby`</li>
</ul>

<p class="mt-2">
  缺少无障碍名称会在开发模式下触发控制台警告。
</p>

### 错误关联

<p>
  错误信息会通过 ARIA 属性自动与文本域关联，以便屏幕阅读器播报。
</p>
