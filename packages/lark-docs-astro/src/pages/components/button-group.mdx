## 何时使用

<p>
  `ButtonGroup` 将少量紧密关联的按钮组合为一个整体控件，最常见的形式是**分裂按钮**：一个主要操作，旁边配一个用于承载相关次要操作的下拉触发器。
</p>

<p>
  <strong>需要把多个彼此独立的按钮或输入框组合起来？</strong> 请改用{" "}
  <a href="/components/toolbar">工具栏（Toolbar）</a>。工具栏（例如格式工具条或页面级的一组操作）需要漫游焦点（roaming focus）的键盘语义，而 `ButtonGroup` 有意不提供该能力。
</p>

</ComponentSection>

## 用法

<p>
  `ButtonGroup` 是一个布局容器。其子元素仍保留各自的 `variant`、`size` 和 `shape`，按钮组只会把内侧圆角压平并让边框重叠，从而让多个按钮共用一条接缝。请为按钮组添加描述该操作的 `aria-label`，并为下拉触发器添加它自己的 `aria-label`。
</p>

  <CodeBlock
    code={`import { Button, ButtonGroup, DropdownMenu } from "@lark-ui/core";
import { CaretDownIcon } from "@phosphor-icons/react";

export default function Example() {
  return (
    <ButtonGroup aria-label="Deploy">
      <Button variant="primary">Deploy</Button>
      <DropdownMenu>
        <DropdownMenu.Trigger
          render={
            <Button
              variant="primary"
              shape="square"
              aria-label="More deploy options"
            >
              <CaretDownIcon />
            </Button>
          }
        />
        <DropdownMenu.Content>
          <DropdownMenu.Item>Deploy to staging</DropdownMenu.Item>
        </DropdownMenu.Content>
      </DropdownMenu>
    </ButtonGroup>
  );
}`}
    lang="tsx"
  />
</ComponentSection>
