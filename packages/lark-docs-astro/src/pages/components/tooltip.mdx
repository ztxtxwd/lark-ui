## 用法

```tsx
import { Tooltip, Button } from "@lark-ui/core";

export default function Example() {
  return (
    <Tooltip content="Tooltip text" render={<Button />}>
      Hover me
    </Tooltip>
  );
}
```

如需在多个工具提示（Tooltip）之间共享延迟分组，请参见 [TooltipProvider](#tooltipprovider)。

## TooltipProvider

<p>
  `TooltipProvider` 会把多个工具提示分组在一起，这样在显示过第一个工具提示之后，
  切换到其他工具提示时就会跳过打开延迟。请在应用根节点或布局中放置一次即可——不要为每个单独的 `Tooltip` 包裹。
</p>

```tsx
// Wrap your app or layout once
<TooltipProvider>
  <App />
</TooltipProvider>

// Then use Tooltip anywhere inside
<Tooltip content="Add" render={<Button shape="square" icon={PlusIcon} />} />
```
