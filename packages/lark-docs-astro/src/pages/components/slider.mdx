## 用法

```tsx
import { Slider } from "@lark-ui/core";

export default function Example() {
  return <Slider label="Volume" defaultValue={40} />;
}
```

滑块（`Slider`）基于 [Base UI 的 Slider](https://base-ui.com/react/components/slider) 构建。`value`、`defaultValue`、`min`、`max`、`step`、`format` 和 `onValueChange` 等属性会直接透传给它。

</ComponentSection>

## 无障碍

- 每个滑块手柄都是原生范围输入框，因此方向键、<kbd>Page Up</kbd>/<kbd>Page Down</kbd> 和 <kbd>Home</kbd>/<kbd>End</kbd> 默认即可使用。
- `label` 为滑块及其手柄命名。如果没有可见标签，请传入 `getAriaLabel`。
- 数值徽标和范围标签对辅助技术隐藏，因为每个手柄已经会播报其格式化后的数值。
